# FarmIt (Vanilla 1.12.1 Fixed Version)

A fixed version of the FarmIt addon from World of Warcraft: The Burning Crusade.

FarmIt is a lightweight farming tracker originally created for World of Warcraft: The Burning Crusade.

This project restores the addon for Vanilla 1.12.1 private servers, fixing compatibility issues and updating broken functions.

✨ Features

4 customizable item tracking slots

Drag an item from your bags to set a tracked item

Shows icon, name, and total carry count

Right-click to clear a slot

Drag the frame to reposition

Lightweight and no dependencies


🛠 Fixes & Improvements (over the original)

Corrected all broken API calls

Replaced unsupported cursor functions with a Vanilla-compatible locked-slot detection method

Fixed bag update events

Fixed VARIABLES_LOADED initialization

Replaced deprecated/globally stored UI calls (getglobal)

Fully compatible with legacy Lua versions missing string.match

*Fixed using ChatGPT
